隐私说明

数据不在网页里。 GitHub 上只是空壳页面，账目数据存在你自己的数据库里，网页源代码里没有任何账目、也没有密钥。
三道围栏。 ① 登录墙：没登录只看到登录页；② 邀请码：就算注册了，没有你家邀请码也进不来；③ 行级安全：数据库端强制只放行同一家庭的数据，别人家一条都读不到。
密钥是公开的、无害的。 anon key 是数据库的公开身份标识，本身不解锁任何数据，真正的锁在登录 + 行级安全。所以它写在仓库里也不泄露隐私。
密码不经本页留存。 登录凭证只发给数据库换取临时令牌，令牌存在你自己的浏览器里，登出即失效。
